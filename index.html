Inversions keep the same chord tones and change the lowest note. Root position has the root in the bass; first inversion has the next chord tone, and so on. Here, chords use compact voicings (extensions fold into one octave); repeated pitch classes are omitted. Use ← → to compare inversions. These are bass-position inversions, not every possible spacing or doubling.
